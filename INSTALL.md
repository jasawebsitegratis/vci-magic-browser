## 🚀 Installation Methods

### Method 1: Portable Version (Recommended for Most Users)

**Keuntungan:**
- ✅ No installation required
- ✅ Can run from USB drive
- ✅ No registry changes
- ✅ Instant startup
- ✅ Easy to remove (just delete folder)

**Cara Install:**

1. Download file: `VCI-Magic-Browser-1.0.0-x64-portable.exe`
2. Extract ke folder mana saja (misal: `C:\VCI Magic Browser`)
3. Double-click `VCI Magic Browser.exe`
4. Enter password: `jasaSEOterdekat.com`
5. Done! ✅

**Data tersimpan di:**
```
C:\VCI Magic Browser\vci-magic-browser-data\
├── groups.json
├── sessions.json
└── config.json
```

---

### Method 2: Installer Version (Windows Standard)

**Keuntungan:**
- ✅ Standard Windows installation
- ✅ Desktop shortcut
- ✅ Start menu entry
- ✅ Uninstall via Control Panel

**Cara Install:**

1. Download file: `VCI-Magic-Browser-1.0.0-x64-installer.exe`
2. Double-click installer
3. Terima License Agreement
4. Pilih `C:\Program Files\` sebagai install location
5. Klik Install
6. Tunggu proses selesai
7. Aplikasi auto-start setelah install
8. Enter password: `jasaSEOterdekat.com`

**Important:** Dengan installer version, aplikasi TIDAK BISA dipindah-pindah! Harus tetap di `C:\Program Files\`.

**Data tersimpan di:**
```
C:\Users\[YourUsername]\AppData\Roaming\vci-magic-browser-data\
├── groups.json
├── sessions.json
└── config.json
```

**Cara Uninstall:**
- Go to: Control Panel → Programs and Features
- Find: "VCI Magic Browser"
- Click: "Uninstall"
- Follow wizard

---

### Method 3: 32-bit Version (Untuk PC Lama)

**Gunakan jika PC Anda 32-bit:**

1. Check sistem: Right-click `My Computer` → Properties
2. Cari info sistem operasi
3. Jika "32-bit", download: `VCI-Magic-Browser-1.0.0-ia32-portable.exe` atau `ia32-installer.exe`
4. Install seperti method 1 atau 2

## ⚙️ Initial Setup

### 1. Set Download Directory (Optional)

1. Click "⚙️ Settings" di top bar
2. Click "Browse" button
3. Pilih folder untuk download
4. Klik "Select Folder"
5. Saved!

Default download folder:
- **Portable**: `AppFolder/vci-magic-browser-data/downloads`
- **Installer**: `C:\Users\[YourUsername]\AppData\Roaming\vci-magic-browser-data\downloads`

### 2. Create First Group

1. Click "+ New Group" button
2. Enter group name (misal: "Facebook")
3. Choose color (optional)
4. Click "Create Group"
5. Group created! ✅

### 3. Add First Tab

1. Select group yang baru dibuat
2. Click "+ Add Tab"
3. Tab "Tab 1" muncul
4. Click tab untuk select
5. Type URL di address bar
6. Press Enter
7. Ready to browse! 🌐

## 🔧 Troubleshooting

### Issue: "Cannot find Node.js"

**Solution:**
- Node.js tidak diperlukan untuk menjalankan aplikasi jadi
- Hanya butuh untuk development/building
- Jika ingin build sendiri, install Node.js dari https://nodejs.org/

### Issue: "Permission Denied" Error

**Solution:**
- Jalankan as Administrator
- Right-click aplikasi → "Run as administrator"
- Check folder permissions

### Issue: "Application Won't Start"

**Solution:**
- Pastikan Windows updated
- Check antivirus tidak block aplikasi
- Try portable version dulu
- Reinstall aplikasi

### Issue: "Data Lost After Update"

**Solution:**
- Data auto-backup di folder aplikasi
- Check folder: `vci-magic-browser-data/`
- Restore dari backup jika ada

### Issue: "High Memory Usage"

**Solution:**
- Close tabs yang tidak digunakan
- Restart aplikasi
- Check browser tabs sedang loading berat
- Update ke versi terbaru
