# Contributing to VCI Magic Browser

Terima kasih telah tertarik untuk berkontribusi pada VCI Magic Browser! Berikut adalah panduan untuk berkontribusi.

## Cara Berkontribusi

### 1. Fork Repository
```bash
git clone https://github.com/[username]/vci-magic-browser.git
cd vci-magic-browser
```

### 2. Buat Branch Fitur
```bash
git checkout -b feature/nama-fitur
```

### 3. Buat Perubahan
- Edit file sesuai kebutuhan
- Test perubahan Anda
- Pastikan tidak ada error

### 4. Commit Perubahan
```bash
git add .
git commit -m "Add: Deskripsi fitur yang ditambahkan"
```

### 5. Push ke Repository
```bash
git push origin feature/nama-fitur
```

### 6. Buat Pull Request
- Buka GitHub repository asli
- Klik "New Pull Request"
- Pilih branch Anda
- Jelaskan perubahan yang dibuat
- Submit PR

## Code Style Guide

### JavaScript/Node.js
- Gunakan `const` dan `let`, hindari `var`
- Use camelCase untuk nama variabel dan function
- Tambahkan comments untuk kode yang kompleks
- Line length max 100 karakter

### Contoh:
```javascript
// Good
const userName = 'John';
function getUserProfile() {
  // implementation
}

// Bad
var user_name = 'John';
function get_user_profile() {
  // implementation
}
```

### HTML/CSS
- Gunakan semantic HTML
- Organize CSS dengan logical grouping
- Gunakan kebab-case untuk class names

## Reporting Bugs

Jika menemukan bug, silakan buka issue dengan:
1. Deskripsi jelas tentang bug
2. Steps untuk reproduce
3. Expected vs actual behavior
4. Screenshot/video jika relevan
5. System info (OS, browser version, dll)

## Feature Requests

Untuk fitur baru:
1. Jelaskan use case
2. Jelaskan expected behavior
3. Jelaskan mengapa ini penting
4. Berikan contoh atau mockup jika ada
